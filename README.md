## How the promo code stacking works

Here's the part most coupon pages get wrong: the extra discount is applied at the payment step, not before it.

The general flow, based on how the checkout is laid out:

1. Open the pricing page through the sale link so the promotional prices are applied.
2. Pick Yearly or Lifetime and click through to checkout, then sign in with email or Google.
3. On the payment page, find **Add promotion code** underneath the subtotal.
4. Enter the code and hit Apply. The extra discount shows up as a line item before you confirm.

The stacking only meaningfully works because the sale price is already applied. A 10% code on a page showing full list price is worse than no code on a page showing the sale.

## The renewal catch nobody mentions in discount articles

This is the most common complaint in AlgoMonster's own community forum, and it's worth knowing before you buy rather than after.

Annual subscriptions auto-renew at the standard rate, not the promotional one. In one posted case, an annual subscription auto-renewed and the user was charged **$119** — noticeably more than the sale price they'd originally paid, and without an advance reminder email. The user cancelled and requested a refund; the platform cancelled the plan and processed the refund, and the user confirmed it arrived, minus a small fee.

Two practical takeaways. If you buy Yearly at a promotional price, set your own calendar reminder a week before the renewal date, because the renewal figure will be the undiscounted one. And if you do get charged unexpectedly, the refund path exists — post in the support forum or email the support address and be explicit that you haven't used the new billing period.

Lifetime buyers skip this entirely, which is a real argument for the one-time plan beyond the price itself.
